# Security Policy

[中文安全政策](./SECURITY.zh-CN.md) | [English](./SECURITY.md)

Please report suspected security vulnerabilities privately. Do not post vulnerability details in public issues or discussion threads.

Use GitHub's private vulnerability reporting feature if it is enabled. Otherwise, contact a repository maintainer privately to request a secure reporting channel. Include:

- Affected component, version, or deployment endpoint
- Reproduction steps
- A minimal proof of concept
- Expected impact and existing mitigations

Remove real access tokens, client secrets, private keys, customer data, and production logs before submitting a report.

After confirmation, coordinate a fix, validation, and disclosure timeline with the maintainer.
